# Socratic Bio Tutor

Study undergraduate biology and chemistry from your notes, syllabus, or
questions. The tutor automatically creates an interactive visual in supported
chats when changing a variable or stepping through a mechanism helps you
understand the concept.

## Skill

[Socratic Bio Tutor](socratic-tutor/SKILL.md) uses a short diagnostic, asks one
question at a time, tracks mastery, and revisits earlier topics.

## Start tutoring

### Install from the GitHub link

In a regular **ChatGPT** chat with Skills available, paste this message.

```text
Can you install this GitHub as a skill?
https://github.com/Vajraaaang/socratic-bio-tutor/blob/main/socratic-tutor/SKILL.md

Use Socratic Bio Tutor as the display name.
Install the full skill folder, including its references and license.
```

Choose **Install** when prompted. Open a new chat with your notes or ask
about a topic from your course.

> Use Socratic Bio Tutor to teach me from these notes.
